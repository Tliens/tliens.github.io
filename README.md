## 说明

- 单文件纯静态页面（`index.html`），无构建、无依赖，直接部署到任意静态托管即可。
- 卡片缩略图直接引用各作品站点的 `og-image.png`，新增作品时在 `index.html` 的 `.grid` 里复制一张卡片并改链接即可。
- 旧 Hexo 博客内容备份在 `hexo-blog-2023` 分支。
